Устанавливаемые клиенты Sharkord для Windows и macOS.

В версии 0.1.6 macOS- и Windows-клиенты запоминают разрешение или запрет
микрофона и камеры отдельно для каждого адреса сервера. Для сброса используйте
меню «Сервер → Сбросить доступ к микрофону и камере» на Mac или одноимённый
пункт в меню значка Sharkord в трее Windows. Системные разрешения ОС остаются
обязательными. Веб-интерфейс также сохраняет выбранное устройство, если его
временно нет в списке до выдачи доступа или подключения; для этой части нужно
обновить сервер.

В версии 0.1.2 исправлена ошибка запуска голоса в macOS: стандартный User-Agent
WKWebView не распознавался библиотекой mediasoup. Клиент теперь передаёт маркер
совместимости Safari, сохраняя сведения о WebKit и версии Sharkord. Добавлены
проверки передачи аудио между двумя нативными Mac-окнами и создания голосового
устройства в настоящем Windows WebView2. Проверки не используют физический
микрофон.

В версии 0.1.1 изменено размещение WebView в macOS: встроенная страница
заполняет отдельный контейнер и следует его размеру при изменении окна,
переключении темы и переходе в полный экран. Добавлена проверка центрирования
экрана входа в настоящем приложении для системной, тёмной и светлой тем.

- Любой сервер Sharkord по HTTPS, в том числе по адресу с подпутём, например `/voice/`.
- Недавние серверы и отдельные профили браузерного хранилища для каждого URL.
- Существующий интерфейс чата, картинок, голосовых каналов и настроек сервера.
- macOS: SwiftUI, WebKit и нативная панель Liquid Glass на macOS 26+, стандартный материал на macOS 14–15.
- Windows: WPF, WebView2 и работа в трее после закрытия окна.
- Кнопка обновления из клиентских релизов этого репозитория с проверкой SHA-256.

Windows 10/11 x64: распакуйте `Sharkord-windows-x64.zip` целиком в папку и запустите `Sharkord.exe`. Нужен Microsoft Edge WebView2 Runtime. Среда .NET уже включена.

macOS 14+, Apple Silicon и Intel: распакуйте `Sharkord-macos-universal.zip` и перенесите `Sharkord.app` в папку «Программы». Сборка имеет локальную подпись и не нотарифицирована Apple. Разрешение на первый запуск можно дать через «Настройки системы → Конфиденциальность и безопасность → Всё равно открыть».

Обновление устанавливается после подтверждения и перезапускает приложение. Настройки серверов и профили хранятся вне папки приложения и сохраняются при обновлении. Для установки обновления папка приложения должна быть доступна для записи.

Видеосвязь и демонстрация экрана зависят от возможностей и разрешений системного WebView. Физические аудиоустройства и голос между реальными устройствами требуют проверки на ваших компьютерах.
